    Run it yourself

    The working system

    The agents run in Omnigent with Claude, and a person approves every checkpoint before new data is revealed. The full code, tests and reports are on GitHub.

    git clone https://github.com/dhyanagni2001-commits/First Fifty-Agentic_battery_cell_triage.git
cd First Fifty-Agentic_battery_cell_triage
uv venv --python 3.12 .venv && uv pip install --python .venv -e ".[dev]" omnigent
.venv/bin/python -m cyclewise.data.download
.venv/bin/python -m cyclewise.data.load_raw && .venv/bin/python -m cyclewise.data.splits
.venv/bin/python -m cyclewise.v2.data --with-b3
.venv/bin/omni run omnigent/cyclewise_v2      # then type: Run the First Fifty study

    Open the repository on GitHub

    Data: Severson et al., "Data-driven prediction of battery cycle life before capacity degradation", Nature Energy 4, 383–391 (2019), dataset from data.matr.io (CC BY 4.0). Labels for cells that were stopped early are shown only in the after-the-run scoring view.
